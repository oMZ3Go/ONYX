## Advisories and remaining inventory

**Resolved — Minimatch, moderate: [GHSA-g3hv-75wg-m249 / CVE-2026-118764](https://github.com/advisories/GHSA-g3hv-75wg-m249).** Versions `>=7.0.0 <11.0.1` can consume excessive CPU and memory when preprocessing attacker-supplied patterns with `optimizationLevel >= 2`; repeated `**/../` transformations amplify internal pattern parts. Version 11.0.9 is outside the affected range. ONYX's affected paths were ESLint/config-array and TypeScript ESLint, using repository-controlled lint/project configuration, not HTTP input. The advisory is absent from the post-update audit.

**Unresolved — Picomatch, high: [GHSA-fc5q-39xc-vjpf / CVE-2026-112366](https://github.com/advisories/GHSA-fc5q-39xc-vjpf).** The reviewed advisory covers versions through **4.0.7** and lists **no patched release**. Crafted repeated single-branch extglob patterns can produce regexes that backtrack excessively against crafted strings and deny service. Exploitation therefore requires a vulnerable matching path and a malicious pattern, not merely the presence of a matching library or an ordinary visitor-supplied URL. No denial-of-service payload was executed during this review.

## Production exposure assessment

| Execution stage    | Verified behavior and trust boundary                                                                                                                                                                                                                                                                                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Installation       | Picomatch is installed by normal dependency resolution. Watcher's install script only invokes `node-gyp rebuild` when `npm_config_build_from_source` is explicitly true; it does not call Picomatch. This is separate from parsing patterns during application requests.                                                                                                                       |
| Build and lint     | ONYX's ESLint configuration has fixed file/ignore patterns. Next Intl's plugin is loaded from `next.config.ts`. Optional message extraction is not configured; its initialization returns without creating the extraction compiler. Builds and CI still depend on trusted repository/configuration inputs.                                                                                     |
| Development        | Vitest/Vite/TypeScript ESLint consume local test/project globs. If Next Intl extraction were enabled, its source watcher starts only in development and generates fixed ignores for `node_modules`, `.next` and `.git`. Watcher's wrapper calls `picomatch.makeRe` for glob-valued `ignore` options and passes the regex source to its native backend. No ONYX visitor controls those options. |
| Production startup | An instrumented local `next start` **does load** Watcher and the audited Picomatch 4.0.7 through Next Intl configuration imports. Loading is not compilation or matching: the probe recorded zero audited Picomatch parsing calls and zero watcher operations. The package must not be described as absent from production merely because its feature is unused.                               |
| Request handling   | Application source has no Picomatch/Minimatch/Watcher imports or glob-pattern input. Locale validation selects one of two fixed JSON imports; route/category identifiers are not compiled as globs. Upload/editing remain unimplemented. Tested requests did not call the audited package.                                                                                                     |

The production build's `.nft.json` traces contain no standalone `node_modules/picomatch`, Minimatch or Watcher paths. They do contain Next's separately bundled `next/dist/compiled/picomatch`. Trace absence alone is insufficient evidence because `next start` reloads the configuration outside the page bundles, as the startup probe demonstrated.

The instrumentation logged module loads and exported matcher/watcher calls on a separate loopback server, with a harmless `*.txt` positive control in a separate process. Eleven bounded HTTP probes covered English/Arabic landing and studio pages, studio query strings containing a harmless glob-shaped marker, a category page, an unknown category, and local/remote image requests. The valid local image returned **200**, the unknown category **404**, and the disallowed remote image **400**. An initial incorrectly addressed local image also returned 404 and is retained in the raw evidence. Next's bundled matcher compiled the fixed `**` pathname pattern twice for the two local image requests; no request value became the compiled pattern. No claim is made that the separately bundled matcher has been independently patched or exhaustively audited.

**Assessment:** no attacker-controlled glob-compilation path was found in ONYX's current production configuration and tested routes. This is a code/configuration review supported by bounded runtime observation, not proof against every possible request or hosting configuration. The installed Picomatch vulnerability remains open. Keep build/development configuration trusted and development servers private; reassess before introducing user-defined globs, extraction settings, file processing or runtime features that use these libraries.

Defer the remaining advisory until an upstream patched Picomatch or a maintained, compatible parent release removes the vulnerable path. The project maintainer should track the advisory, re-audit before deployment, and repeat this exposure review whenever the relevant dependency/configuration changes. No automatic monitoring or deployment exception has been created.
