# Non-functional requirements

Correctness, security, mobile usability and maintainability are **C**. Numerical targets below are **R**, initial measurable gates to validate against representative devices and network conditions; none are measured Phase 00 performance claims.

| ID                           | Gate                                                                                                                                             | Measurement / owner                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| NFR-01 Accessibility         | Target WCAG 2.2 AA; keyboard alternatives to gestures; labeled tools, focus management, contrast and reduced motion                              | Automated checks plus manual keyboard/screen-reader review; designer + QA                                                |
| NFR-02 Storefront speed      | LCP ≤2.5 s, INP ≤200 ms, CLS ≤0.1 at p75 once field samples suffice                                                                              | Lab proxy on recorded mid-tier Android + throttled network before release; field monitoring only after privacy decisions |
| NFR-03 Editor responsiveness | At 100 objects, p95 interaction-to-render ≤50 ms over 30 s drag/transform trials; no freeze >200 ms during ordinary edits                        | Spike traces, five runs on named baseline hardware; see spike exceptions for exports                                     |
| NFR-04 Resource budget       | Initial storefront route JS target ≤180 KiB gzip, no editor chunk on discovery routes; hero images responsive                                    | Production bundle/network audit; final budget approved after P01                                                         |
| NFR-05 Recovery              | Two local slots remain consistent after failed writes/imports; save status within 2 s after ordinary idle editing (excluding large asset import) | Fault injection, reload and multi-tab tests in P04                                                                       |
| NFR-06 Data integrity        | Exact decimal/integer monetary arithmetic; immutable order/design/rule revisions; idempotent order finalization                                  | Unit, concurrency and database integration tests                                                                         |
| NFR-07 Security              | Deny cross-customer access, privileged client keys and unauthenticated admin writes; validate all untrusted inputs                               | Abuse tests, RLS/storage tests and least-privilege review before P07 exit                                                |
| NFR-08 Compatibility         | Named supported browser/device matrix, including Instagram/TikTok embedded browsers                                                              | P02 real-device tests; framework minimums alone do not establish product support                                         |
| NFR-09 Maintainability       | Strict TypeScript, independent domain tests, explicit module ownership, documented migrations and exact dependency pins                          | Review + lint/type/test/build checks on each meaningful change                                                           |
| NFR-10 Operability/privacy   | Correlated errors without secrets/art/customer content; retention/deletion and backups with restore drills                                       | Owner-approved retention, RPO/RTO and incident owner required before pilot; values U                                     |
| NFR-11 Print fidelity        | Unit-safe physical coordinates; deterministic supported fonts; expected raster dimensions/alpha per side                                         | Reference fixtures and actual supplier sample approval                                                                   |
| NFR-12 Responsive behavior   | No page-level horizontal overflow from 320 CSS px; useful 200% zoom/reflow; touch targets aim for 44×44 CSS px                                   | P01/P04 manual and browser tests; allow canvas viewport panning rather than forcing the page wider                       |

WCAG target references the [W3C standard](https://www.w3.org/TR/WCAG22/). Gesture-only editing is insufficient: object selection, position/size inputs and a DOM layer list provide alternatives. UI locale direction and text-object direction are independent.
