Working assumptions (**R**, not facts): modular monolith; Supabase preferred; canonical millimetre coordinates; ZIP-based `.onyx` package; 300 PPI initial test target; private guest capability links; single-item request UX; licensed font allowlist. See ADRs for tradeoffs. None authorizes infrastructure provisioning.

Review sequence: owner supplies brand/catalog/locale → supplier confirms print constraints → P02 resolves engine/format feasibility → owner approves pricing/order/privacy policies → P05/P06 implement. Unknowns do not block Phase 00 documentation completion, but they do block the dependent release gates.
